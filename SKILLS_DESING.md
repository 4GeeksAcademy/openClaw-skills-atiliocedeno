## Skills instaladas

El agente cuenta con las siguientes skills de OpenClaw para ampliar sus capacidades:

- **GitHub:** Permite interactuar con repositorios de GitHub, revisar Pull Requests, consultar Issues, inspeccionar commits y obtener información de los proyectos.
- **PR Status Monitor:** Skill personalizado que revisa el PR entregado cada 5 horas, valida los checks de CI, detecta bloqueos o conflictos y te informa el estado actual del mismo.
- **Telegram:** Permite enviar notificaciones, recordatorios, resúmenes y actualizaciones de progreso directamente a través de Telegram para mantener una comunicación rápida y eficiente.
